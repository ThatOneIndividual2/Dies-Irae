# Demons

Hell is an overlay with agency, not a feudal faction.

- Pure simulation: `app/Domain/Hell`
- Laravel contract: `DemonsContract` / `DemonsService`
- Mutations: `app/Actions/Hell`
- Content: `database/data/hell/`
- Architecture: `docs/architecture/DEMONIC_THREAT_ENGINE.md`

A demonic faction is not a Realm, Dynasty, or Title. Named demons do not respawn on pulse.
